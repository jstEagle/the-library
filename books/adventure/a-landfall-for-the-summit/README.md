# A Landfall for the Summit

*by Ansel Whitlock*

> Paloma Voss, a salvage diver working a wreck the navy won't discuss, knows the wilderness forgives nothing and forgets less. But when an expedition upriver stops answering the radio, he discovers that staying invisible was never really an option. Now he must follow a river upstream to its forbidden source, and time is already running out.
