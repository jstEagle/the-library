# A Trail for the Landfall

*by Jude Crane*

> Edmund Joubert, a railroad engineer with a map of closed lines, knows the wilderness forgives nothing and forgets less. But when the tide reveals a cave that legends charge admission to, they discover that staying invisible was never really an option. Now they must bring the expedition home without telling anyone what it found, and time is already running out.
