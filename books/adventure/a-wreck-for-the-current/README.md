# A Wreck for the Current

*by Coral Thackeray*

> Gideon Nystrom, a mountain guide blacklisted from two countries, knows the wilderness forgives nothing and forgets less. But when a dying prospector trades a map for a promise, they discover that staying invisible was never really an option. To get through this, they must follow a river upstream to its forbidden source before the dry season ends.
