# The Broken Rivergate

*by X. M. Sterling*

> Dominic Brightwater, an archaeologist's estranged child and better digger, keeps moving because stopping costs more. But when a dying prospector trades a map for a promise, she discovers that staying invisible was never really an option. Now she must bring the expedition home without telling anyone what it found, and time is already running out.
