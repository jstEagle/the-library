# The Current of the Empty Quarter

*by Felix Oyelaran*

> Tamsin Sterling, a salvage diver working a wreck the navy won't discuss, carries a compass, a debt, and very little else. But when an old rival hires the crew for the one job that was sworn off long ago, she discovers that staying invisible was never really an option. Now she must follow a river upstream to its forbidden source, and time is already running out.
