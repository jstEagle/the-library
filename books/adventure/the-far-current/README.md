# The Far Current

*by Ivo Crane*

> Petra Coldharbour, a riverboat captain who knows every sandbar's mood, knows the wilderness forgives nothing and forgets less. But when the tide reveals a cave that legends charge admission to, she discovers that staying invisible was never really an option. Now she must outlast the monsoon with a leaking boat and a stranger's help, and time is already running out.
