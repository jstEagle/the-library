# The Rough Passage

*by Sable Voss*

> Lena Eriksen, an archaeologist's estranged child and better digger, carries a compass, a debt, and very little else. But when an old rival hires the crew for the one job that was sworn off long ago, she discovers that staying invisible was never really an option. Now she must beat the salvage fleet to the wreck by six tides, and time is already running out.
