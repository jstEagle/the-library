# The Salt Landfall

*by Theo Nakamura*

> Sable Oyelaran, a railroad engineer with a map of closed lines, keeps moving because stopping costs more. But when a dying prospector trades a map for a promise, he discovers that staying invisible was never really an option. Now he must beat the salvage fleet to the wreck by six tides, and time is already running out.
