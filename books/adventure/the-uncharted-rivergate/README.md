# The Uncharted Rivergate

*by Jonah Hartwell*

> Marguerite Winterbourne, an archaeologist's estranged child and better digger, knows the wilderness forgives nothing and forgets less. But when an old rival hires the crew for the one job that was sworn off long ago, she discovers that staying invisible was never really an option. To get through this, she must outlast the monsoon with a leaking boat and a stranger's help before the monsoon makes landfall.
