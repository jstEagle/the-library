# When the Current Turns

*by Mara Sterling*

> Zephyrine Sandoval, an archaeologist's estranged child and better digger, has spent seven years measuring life in miles rather than years. But when an expedition upriver stops answering the radio, she discovers that staying invisible was never really an option. Now she must beat the salvage fleet to the wreck by six tides, and time is already running out.
