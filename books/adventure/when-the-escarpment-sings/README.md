# When the Escarpment Sings

*by Zephyrine Montrose*

> Cyrus Eriksen, a mountain guide blacklisted from two countries, keeps moving because stopping costs more. But when an old rival hires the crew for the one job that was sworn off long ago, they discover that staying invisible was never really an option. To get through this, they must beat the salvage fleet to the wreck by six tides before the monsoon makes landfall.
