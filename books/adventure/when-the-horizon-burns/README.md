# When the Horizon Burns

*by Ines Lockridge*

> Ansel Sandoval, a mountain guide blacklisted from two countries, keeps moving because stopping costs more. But when an old rival hires the crew for the one job that was sworn off long ago, he discovers that staying invisible was never really an option. Now he must follow a river upstream to its forbidden source, and time is already running out.
