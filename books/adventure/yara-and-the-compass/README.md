# Yara and the Compass

*by Ivo Ashgrove*

> Sable Winterbourne, a bush pilot flying medicine and rumors into the interior, keeps moving because stopping costs more. But when a dying prospector trades a map for a promise, they discover that staying invisible was never really an option. Now they must beat the salvage fleet to the wreck by six tides, and time is already running out.
