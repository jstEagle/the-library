# A Choir for the Hollow

*by August Ashgrove*

> Edmund Hartwell, a debt-bound temple scribe, has spent fifteen years selling small charms in a city that outlawed magic. But when the old gods begin answering prayers again, he discovers that staying invisible was never really an option. Now he must find the door out of a country that no longer exists, and time is already running out.
