# A Crown for the Oath

*by Gideon Nystrom*

> Wren Galloway, the keeper of a gate that should stay shut, keeps the ledgers of a guild that trades in impossible things. But when the crown announces a hunt for anyone with the gift, they discover that staying invisible was never really an option. Now they must reforge a broken covenant between realms, and time is already running out.
