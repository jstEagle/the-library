# A Garden for the Hollow

*by L. M. Zhou*

> Juniper Villalobos, the last oath-bound swordspeaker, has spent seven years selling small charms in a city that outlawed magic. But when a child arrives at the door speaking a language that predates kingdoms, she discovers that staying invisible was never really an option. Now she must reforge a broken covenant between realms, and time is already running out.
