# A Hollow for the Choir

*by L. M. Brightwater*

> Petra Whitlock, a beast-speaker hiding a forbidden gift, has spent twenty years selling small charms in a city that outlawed magic. But when the old gods begin answering prayers again, she discovers that staying invisible was never really an option. Now she must reforge a broken covenant between realms, and time is already running out.
