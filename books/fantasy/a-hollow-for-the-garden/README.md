# A Hollow for the Garden

*by Felix Dunmore*

> Kestrel Quintana, a debt-bound temple scribe, has never left the valley where magic cannot follow. But when the old gods begin answering prayers again, she discovers that staying invisible was never really an option. Now she must steal back a soul sold to the court beneath the mountain, and time is already running out.
