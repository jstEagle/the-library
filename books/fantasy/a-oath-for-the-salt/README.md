# A Oath for the Salt

*by Emrys Almeida*

> Paloma Galloway, the last oath-bound swordspeaker, has spent twenty years selling small charms in a city that outlawed magic. But when the crown announces a hunt for anyone with the gift, she discovers that staying invisible was never really an option. Now she must find the door out of a country that no longer exists, and time is already running out.
