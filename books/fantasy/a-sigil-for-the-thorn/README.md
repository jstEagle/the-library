# A Sigil for the Thorn

*by Emrys Dunmore*

> Marguerite Quintana, a mercenary sworn to a god that went silent, has never left the valley where magic cannot follow. But when the border wards fall on the same night the stars go out, they discover that staying invisible was never really an option. Now they must carry a secret that could reignite an ancient war, and time is already running out.
