# A Spire for the Crown Again

*by Yara Halloran*

> Freya Joubert, a beast-speaker hiding a forbidden gift, keeps the ledgers of a guild that trades in impossible things. But when the crown announces a hunt for anyone with the gift, she discovers that staying invisible was never really an option. Now she must reforge a broken covenant between realms, and time is already running out.
