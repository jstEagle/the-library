# A Spire for the Garden

*by Sable Vasquez*

> Juniper Brightwater, the keeper of a gate that should stay shut, keeps the ledgers of a guild that trades in impossible things. But when tonight's date appears in a book of prophecies written a century ago, they discover that staying invisible was never really an option. Now they must find the door out of a country that no longer exists, and time is already running out.
