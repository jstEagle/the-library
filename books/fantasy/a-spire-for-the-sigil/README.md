# A Spire for the Sigil

*by Rosalind Ishikawa*

> Isandro Galloway, a mercenary sworn to a god that went silent, keeps the ledgers of a guild that trades in impossible things. But when the border wards fall on the same night the stars go out, she discovers that staying invisible was never really an option. Now she must unbind a king from the thing wearing his crown, and time is already running out.
