# Ashvale Rising Anew

*by Odile Montrose*

> Freya Reyes, a mercenary sworn to a god that went silent, has never left the valley where magic cannot follow. But when a child arrives at the door speaking a language that predates kingdoms, they discover that staying invisible was never really an option. Now they must carry a secret that could reignite an ancient war, and time is already running out.
