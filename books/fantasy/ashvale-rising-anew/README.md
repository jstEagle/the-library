# Ashvale Rising Anew

*by Ada Lockridge*

> Rafael Pemberton, a beast-speaker hiding a forbidden gift, has spent fifteen years selling small charms in a city that outlawed magic. But when a child arrives at the door speaking a language that predates kingdoms, he discovers that staying invisible was never really an option. To get through this, he must reforge a broken covenant between realms before the last dragon-fire gutters out.
