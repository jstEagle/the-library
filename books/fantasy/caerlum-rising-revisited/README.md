# Caerlum Rising Revisited

*by Astrid Dravenmoor*

> Tamsin Thornbury, a mercenary sworn to a god that went silent, has spent five years selling small charms in a city that outlawed magic. But when a dying stranger presses a map into unwilling hands, they discover that staying invisible was never really an option. Now they must carry a secret that could reignite an ancient war, and time is already running out.
