# Emrys and the Ember

*by Marguerite Yarrow*

> Noor Lockridge, the keeper of a gate that should stay shut, knows every smuggler's road through the Thornfell mountains. But when the old gods begin answering prayers again, they discover that staying invisible was never really an option. Now they must reforge a broken covenant between realms, and time is already running out.
