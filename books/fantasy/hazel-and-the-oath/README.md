# Hazel and the Oath

*by Petra Hartwell*

> Sebastian Okafor, an exiled storm-caller, has spent twelve years selling small charms in a city that outlawed magic. But when a dying stranger presses a map into unwilling hands, he discovers that staying invisible was never really an option. Now he must reforge a broken covenant between realms, and time is already running out.
