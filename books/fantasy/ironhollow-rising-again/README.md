# Ironhollow Rising Again

*by Jude Kavanagh*

> Sable Quintana, a royal food-taster building immunity one dish at a time, has never left the valley where magic cannot follow. But when a dying stranger presses a map into unwilling hands, he discovers that staying invisible was never really an option. To get through this, he must carry a secret that could reignite an ancient war before the last dragon-fire gutters out.
