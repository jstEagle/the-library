# Isandro and the Crown

*by Jonah Dravenmoor*

> Hazel Montrose, a hedge-witch's runaway apprentice, keeps the ledgers of a guild that trades in impossible things. But when a child arrives at the door speaking a language that predates kingdoms, she discovers that staying invisible was never really an option. Now she must find the door out of a country that no longer exists, and time is already running out.
