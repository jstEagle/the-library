# Lena and the Oath

*by Sebastian Hartwell*

> Petra Vasquez, the keeper of a gate that should stay shut, has never left the valley where magic cannot follow. But when a dying stranger presses a map into unwilling hands, they discover that staying invisible was never really an option. Now they must steal back a soul sold to the court beneath the mountain, and time is already running out.
