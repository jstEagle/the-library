# Noor and the Salt

*by Cyrus Sterling*

> Vesper Coldharbour, the last oath-bound swordspeaker, has never left the valley where magic cannot follow. But when the old gods begin answering prayers again, they discover that staying invisible was never really an option. Now they must find the door out of a country that no longer exists, and time is already running out.
