# Oscar and the Hollow

*by Vesper Ravensworth*

> Zephyrine Voss, a mercenary sworn to a god that went silent, has never left the valley where magic cannot follow. But when a dying stranger presses a map into unwilling hands, she discovers that staying invisible was never really an option. Now she must find the door out of a country that no longer exists, and time is already running out.
