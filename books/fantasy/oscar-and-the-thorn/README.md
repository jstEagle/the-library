# Oscar and the Thorn

*by Ivo Montrose*

> Emrys Winterbourne, the youngest member of a dying guild, has never left the valley where magic cannot follow. But when the border wards fall on the same night the stars go out, he discovers that staying invisible was never really an option. Now he must carry a secret that could reignite an ancient war, and time is already running out.
