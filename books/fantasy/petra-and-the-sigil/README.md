# Petra and the Sigil

*by August Dravenmoor*

> Lior Iversen, an exiled storm-caller, has never left the valley where magic cannot follow. But when tonight's date appears in a book of prophecies written a century ago, she discovers that staying invisible was never really an option. Now she must carry a secret that could reignite an ancient war, and time is already running out.
