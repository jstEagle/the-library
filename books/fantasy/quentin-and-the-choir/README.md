# Quentin and the Choir

*by Ada Brightwater*

> Freya Voss, a debt-bound temple scribe, has spent fifteen years selling small charms in a city that outlawed magic. But when the border wards fall on the same night the stars go out, they discover that staying invisible was never really an option. Now they must reforge a broken covenant between realms, and time is already running out.
