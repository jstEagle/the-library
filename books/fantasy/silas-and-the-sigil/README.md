# Silas and the Sigil

*by Lena Blackwood*

> Gideon Pemberton, a debt-bound temple scribe, knows every smuggler's road through the Thornfell mountains. But when a dying stranger presses a map into unwilling hands, they discover that staying invisible was never really an option. Now they must carry a secret that could reignite an ancient war, and time is already running out.
