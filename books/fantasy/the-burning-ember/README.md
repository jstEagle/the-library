# The Burning Ember

*by Mara Fairweather*

> Oscar Dravenmoor, a cartographer of unmapped realms, knows every smuggler's road through the Thornfell mountains. But when the old gods begin answering prayers again, she discovers that staying invisible was never really an option. Now she must reforge a broken covenant between realms, and time is already running out.
