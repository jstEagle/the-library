# The Burning Spire

*by Freya Blackwood*

> Jude Kavanagh, a thief who steals memories, has spent three years selling small charms in a city that outlawed magic. But when the border wards fall on the same night the stars go out, he discovers that staying invisible was never really an option. Now he must reforge a broken covenant between realms, and time is already running out.
