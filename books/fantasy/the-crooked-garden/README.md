# The Crooked Garden

*by Odile Voss*

> Paloma Brightwater, a royal food-taster building immunity one dish at a time, has never left the valley where magic cannot follow. But when tonight's date appears in a book of prophecies written a century ago, they discover that staying invisible was never really an option. Now they must find the door out of a country that no longer exists, and time is already running out.
