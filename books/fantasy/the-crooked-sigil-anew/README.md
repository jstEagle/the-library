# The Crooked Sigil Anew

*by Sable Voss*

> Elodie Yarrow, the youngest member of a dying guild, has spent ten years selling small charms in a city that outlawed magic. But when a child arrives at the door speaking a language that predates kingdoms, they discover that staying invisible was never really an option. Now they must reforge a broken covenant between realms, and time is already running out.
