# The Drowned Thorn

*by Mara Fairweather*

> Theo Villalobos, the last oath-bound swordspeaker, has never left the valley where magic cannot follow. But when the crown announces a hunt for anyone with the gift, they discover that staying invisible was never really an option. Now they must carry a secret that could reignite an ancient war, and time is already running out.
