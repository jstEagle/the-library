# The Ember of Ashvale

*by Hazel Sandoval*

> Mara Joubert, a hedge-witch's runaway apprentice, knows every smuggler's road through the Thornfell mountains. But when the border wards fall on the same night the stars go out, they discover that staying invisible was never really an option. Now they must find the door out of a country that no longer exists, and time is already running out.
