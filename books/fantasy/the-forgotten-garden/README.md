## About the author

Orsen Reyes is the pen name of a former archivist who spent a decade cataloguing unclaimed heirlooms in a coastal customs house, where every object seemed to be waiting for someone. The Forgotten Garden is their second novel, following the quietly acclaimed novella Salt for the Dead.
