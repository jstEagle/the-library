# The Forgotten Spire

*by Lior Joubert*

> Kestrel Halloran, the keeper of a gate that should stay shut, has spent seven years selling small charms in a city that outlawed magic. But when the old gods begin answering prayers again, he discovers that staying invisible was never really an option. Now he must find the door out of a country that no longer exists, and time is already running out.
