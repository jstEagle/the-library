# The Gilded Crown

*by Gideon Ashgrove*

> Theo Underhill, the keeper of a gate that should stay shut, has never left the valley where magic cannot follow. But when a dying stranger presses a map into unwilling hands, they discover that staying invisible was never really an option. Now they must unbind a king from the thing wearing his crown, and time is already running out.
