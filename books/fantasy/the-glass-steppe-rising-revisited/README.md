# the Glass Steppe Rising Revisited

*by T. M. Hartwell*

> Felix Kavanagh, the last oath-bound swordspeaker, has spent ten years selling small charms in a city that outlawed magic. But when a dying stranger presses a map into unwilling hands, they discover that staying invisible was never really an option. To get through this, they must reforge a broken covenant between realms before the last dragon-fire gutters out.
