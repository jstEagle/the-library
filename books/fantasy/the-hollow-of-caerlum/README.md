# The Hollow of Caerlum

*by Rosalind Sterling*

> Emrys Marchetti, an exiled storm-caller, has never left the valley where magic cannot follow. But when the old gods begin answering prayers again, they discover that staying invisible was never really an option. To get through this, they must reforge a broken covenant between realms before the last dragon-fire gutters out.
