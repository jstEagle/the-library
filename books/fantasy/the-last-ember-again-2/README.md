# The Last Ember Again

*by Gideon Thackeray*

> Noor Winterbourne, a bone-carver who hears the dead, has never left the valley where magic cannot follow. But when a child arrives at the door speaking a language that predates kingdoms, she discovers that staying invisible was never really an option. Now she must find the door out of a country that no longer exists, and time is already running out.
