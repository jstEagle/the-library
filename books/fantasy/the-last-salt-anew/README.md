# The Last Salt Anew

*by Casper Dravenmoor*

> Marguerite Vasquez, an exiled storm-caller, keeps the ledgers of a guild that trades in impossible things. But when the border wards fall on the same night the stars go out, he discovers that staying invisible was never really an option. To get through this, he must find the door out of a country that no longer exists before the long winter finishes falling.
