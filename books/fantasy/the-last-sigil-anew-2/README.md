# The Last Sigil Anew

*by Gideon Dravenmoor*

> Coral Nystrom, a beast-speaker hiding a forbidden gift, has spent twelve years selling small charms in a city that outlawed magic. But when the old gods begin answering prayers again, they discover that staying invisible was never really an option. Now they must find the door out of a country that no longer exists, and time is already running out.
