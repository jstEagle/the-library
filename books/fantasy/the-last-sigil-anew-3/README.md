# The Last Sigil Anew

*by Coral Thackeray*

> Oscar Thackeray, the keeper of a gate that should stay shut, has spent twenty years selling small charms in a city that outlawed magic. But when a child arrives at the door speaking a language that predates kingdoms, they discover that staying invisible was never really an option. To get through this, they must find the door out of a country that no longer exists before the last dragon-fire gutters out.
