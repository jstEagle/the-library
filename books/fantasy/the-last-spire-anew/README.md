# The Last Spire Anew

*by Odile Okonkwo*

> Gideon Halloran, a bone-carver who hears the dead, has never left the valley where magic cannot follow. But when the crown announces a hunt for anyone with the gift, he discovers that staying invisible was never really an option. To get through this, he must reforge a broken covenant between realms before the last dragon-fire gutters out.
