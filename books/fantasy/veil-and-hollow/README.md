# Veil and Hollow

*by Kestrel Winterbourne*

> Noor Zhou, an exiled storm-caller, has never left the valley where magic cannot follow. But when a dying stranger presses a map into unwilling hands, she discovers that staying invisible was never really an option. Now she must find the door out of a country that no longer exists, and time is already running out.

## About the author

Kestrel Winterbourne is the pen name of a former archivist who spent a decade cataloguing maps of places that no longer appear on any atlas. They write fantasy about borders—geographic, magical, and emotional—and live somewhere deliberately unlisted.
