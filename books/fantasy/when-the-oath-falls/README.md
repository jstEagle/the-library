# When the Oath Falls

*by Rosalind Thornbury*

> Lena Dravenmoor, a debt-bound temple scribe, has never left the valley where magic cannot follow. But when the crown announces a hunt for anyone with the gift, they discover that staying invisible was never really an option. Now they must reforge a broken covenant between realms, and time is already running out.
