# When the Salt Wakes

*by Paloma Almeida*

> Paloma Thackeray, a royal food-taster building immunity one dish at a time, has never left the valley where magic cannot follow. But when a child arrives at the door speaking a language that predates kingdoms, they discover that staying invisible was never really an option. Now they must find the door out of a country that no longer exists, and time is already running out.
