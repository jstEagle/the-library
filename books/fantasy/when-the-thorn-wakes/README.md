# When the Thorn Wakes

*by C. M. Eriksen*

> Rafael Nystrom, a mercenary sworn to a god that went silent, keeps the ledgers of a guild that trades in impossible things. But when a child arrives at the door speaking a language that predates kingdoms, they discover that staying invisible was never really an option. Now they must steal back a soul sold to the court beneath the mountain, and time is already running out.
