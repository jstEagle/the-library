# When the Veil Burns Again

*by Elodie Sandoval*

> Odile Oyelaran, the last oath-bound swordspeaker, knows every smuggler's road through the Thornfell mountains. But when a child arrives at the door speaking a language that predates kingdoms, they discover that staying invisible was never really an option. Now they must find the door out of a country that no longer exists, and time is already running out.
