# When the Veil Falls

*by Lena Almeida*

> Elodie Ashgrove, a debt-bound temple scribe, has never left the valley where magic cannot follow. But when tonight's date appears in a book of prophecies written a century ago, he discovers that staying invisible was never really an option. Now he must carry a secret that could reignite an ancient war, and time is already running out.
