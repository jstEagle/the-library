# A Atlas for the Lantern

*by Theo Underhill*

> Vesper Joubert, a code-carrying courier on the last diplomatic mission of a doomed republic, measures the world in what can be carried when the orders come. But when the bridge — the only road out — closes for the season, he discovers that staying invisible was never really an option. Now he must finish the work while the workshop still stands, and time is already running out.
