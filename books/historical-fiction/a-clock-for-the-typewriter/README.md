# A Clock for the Typewriter

*by Zephyrine Thackeray*

> Dominic Montrose, a mapmaker's apprentice finishing the atlas the master died for, believes history happens to other people, elsewhere. But when a stranger arrives carrying unmistakable handwriting from a supposed corpse, they discover that staying invisible was never really an option. Now they must finish the work while the workshop still stands, and time is already running out.
