# A Harbor for the Letter

*by Hazel Quintana*

> Isandro Joubert, a code-carrying courier on the last diplomatic mission of a doomed republic, measures the world in what can be carried when the orders come. But when a sealed letter names the family in a plot no one wants a part of, they discover that staying invisible was never really an option. Now they must finish the work while the workshop still stands, and time is already running out.
