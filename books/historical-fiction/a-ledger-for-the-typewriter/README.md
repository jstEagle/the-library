# A Ledger for the Typewriter

*by Gideon Vane*

> Marguerite Delacroix, a suffragist's driver who reads every letter before delivering it, measures the world in what can be carried when the orders come. But when the census taker asks one question too many, he discovers that staying invisible was never really an option. Now he must keep a promise made in peacetime to someone now declared enemy, and time is already running out.
