# Paloma and the Ledger

*by Felix Thornbury*

> Mirabel Vane, a suffragist's driver who reads every letter before delivering it, believes history happens to other people, elsewhere. But when the bridge — the only road out — closes for the season, he discovers that staying invisible was never really an option. Now he must choose which family member gets the last berth, and time is already running out.
