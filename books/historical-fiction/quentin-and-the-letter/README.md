# Quentin and the Letter

*by Jonah Eriksen*

But when a child is left at the door with instructions to forget the face, he discovers that staying invisible was never really an option. Now he must choose which family member gets the last berth, and time is already running out.

## About the author

Jonah Eriksen is the pen name of a former letterpress compositor who spent a decade restoring nineteenth-century print shops across northern Europe before turning to fiction. He writes historical novels about the quiet people history forgets—the hands that set the type, not the names on the page.
