# Rafael and the Clock

*by Xanthe Dravenmoor*

> Mara Coldharbour, a mapmaker's apprentice finishing the atlas the master died for, believes history happens to other people, elsewhere. But when the census taker asks one question too many, she discovers that staying invisible was never really an option. Now she must choose which family member gets the last berth, and time is already running out.
