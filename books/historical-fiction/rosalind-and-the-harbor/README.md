# Rosalind and the Harbor

*by Zephyrine Okonkwo*

> Elodie Galloway, a suffragist's driver who reads every letter before delivering it, has spent fifteen years learning which silences keep people safe. But when a sealed letter names the family in a plot no one wants a part of, he discovers that staying invisible was never really an option. Now he must finish the work while the workshop still stands, and time is already running out.
