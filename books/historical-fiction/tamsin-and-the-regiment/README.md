# Tamsin and the Regiment

*by Oscar Underhill*

> Coral Okonkwo, a code-carrying courier on the last diplomatic mission of a doomed republic, has spent fifteen years learning which silences keep people safe. But when the bridge — the only road out — closes for the season, she discovers that staying invisible was never really an option. Now she must finish the work while the workshop still stands, and time is already running out.
